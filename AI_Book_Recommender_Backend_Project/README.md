# AI Book Recommender Backend

Backend-first project for a Computer Science book recommendation system.

Install:
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

Run after Antigravity implements the app:
uvicorn app.main:app --reload

Swagger:
http://127.0.0.1:8000/docs

See docs/ANTIGRAVITY_BACKEND_PROMPT.txt for the main implementation prompt.
